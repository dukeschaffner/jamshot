Home page serving both marketing and app content

Is there a "better" pattern?
For a production app at scale, the cleaner version is server-side session detection:

// page.js — ideal long-term
const session = await getServerSession();
if (session?.user) return <HomeFeed />;
return <MarketingHome page={marketingPage} />;
That gives you:

No marketing flash for logged-in users
No client gate on /
Simpler mental model
You don't have server session reading wired up yet, so the current pattern is a good interim fix, not the final architecture.
