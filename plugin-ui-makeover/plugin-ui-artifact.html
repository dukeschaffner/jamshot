Help

  1. Sample rate: Prefer a 44.1 kHz host / project sample rate for best results.
  2. Log in: Use Log in to Sterio, or open a track from the Sterio web app via Open in Plugin.
  3. Sync playback: Match the metronome and time signature in your DAW. Start playback from the timeline start so the plugin can sync.
  4. After recording: Bounce / export as WAV from your DAW, then import / upload in the Sterio web DAW.
  5. Sync edits: After editing in the web DAW, use Sync edits to plugin to push changes back here.
