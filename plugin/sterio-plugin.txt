

MVP:
- use JUCE framework for the plugin
- login to sterio (ideally using website login page in system browser)
- load liked tracks for user from api, newest first, load the first 15 and show load more button if necessary. also have refresh button
- tracks appear in list with basic track info. each should should have a "select" button. only one track can be selected at a time.
- when a track is selected, it loads the track's stems and region metadata (see example-mix-gains.json for example). the region metadata gives start times, end times, and offsets for each region based on the stem audio. gain values are also provided for each stem.
- if track is selected and they start playback in DAW, the plugin should playback the stems using the region metadata and gain values in perfect sync with the DAW's transport state




Post MVP:
- add ability for the user to upload a track directly from the plugin. This also has options:
    - user drags region/file into the plugin and the plugin uploads directly to the api
    - user drags region/file into the plugin and the plugin uploads audio and metadata to temp storage and opens the web app to allow the user to upload the track using the temp assets
- how to ensure recorded audio captures signal chain? (warn users to bounce the track to ensure audio captures signal chain OR maybe allow the plugin to record audio directly?)
