Explore a vertical, full-screen “TikTok-style” feed experience for browsing tracks.

Each user can have a single **user-wide canvas video** that plays in that feed context: about **8 seconds** long, **16:9** aspect ratio, replaceable at any time. The same clip would accompany **all tracks by that user** when they appear in this view (not per-track assets).

Acceptance direction (when implemented): define how the canvas loops or hands off to track audio, storage/upload limits, moderation, and how it behaves for users who have not set a canvas video.
