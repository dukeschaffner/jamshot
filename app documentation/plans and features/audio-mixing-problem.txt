this application auto mixes two files (with user-specified gain values) and normalizes the audio for consistency across the application.


when a user uploads a original track, no mixing, just normalization
when a user uploads a collaboration track, we mix the two files and normalize the audio for consistency across the application


this is my understanding of how the processing works:
so for original track:
inputA * gainA -> normalize -> outputA

and for collaboration track:
inputA * gainA -> normalize -> outputA
inputB * gainB -> normalize -> outputB
outputA + outputB -> normalize -> outputC

Now let's say someone adds a new collab on outputC track:
inputC * gainC -> normalize -> outputC
inputD * gainD -> normalize -> outputD
outputC + outputD -> normalize -> outputE
