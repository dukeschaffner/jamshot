
loop listening mode
- track which tracks/collabs are "loops" - a loop is a track that is one or more loops (an even multiple of measures/bars)
    - for now, I will just manually mark track as loop in the db
- tracks that have loop listening mode enabled will disable arrangement features in the DAW when collabing. This includes editting regions and changing project duration. this preserves the loop integrity/timing.
- on the track tree page, users can listen in loop listening mode
    - this mode cycles through all the loop tracks in such a way that it sounds like a continuous loop/song.
- algorithmically navigates the tree, playing the tracks (depth first navigation)
    - this naturally adds/removes/changes layers of the loop so the song/audio is always evolving
    - users can also queue a track to play at the end of the current loop
    - users can cycle a track so that it keeps playing
- really cool for House beats -> results in continuous loop/song but users can navigate through or swap out different loops/layers from other users.
    - also potentially good for hip hop, lofi, trap, etc.
- bpm/time signature will be locked to the root track and cannot be changed
