
<BACKGROUND>
This is an app/website that allows music artists to asynchronously collaborate with smaller artists/fans, but in more of a social media format. for instance, an artist would upload a clip that they recorded, and people could attach an audio file onto the original recording as a new version. the app has a like/ranking system and has a featured page to show popular collabs.
</BACKGROUND>

<TECH_STACK_AND_INTEGRATIONS>
  - Frontend: Next.js hosted on AWS Amplify
  - Backend: 
    - API: Express.js hosted on AWS Lambda (basic CRUD operations)
    - Lambda functions:
      - audio processing
      - analytics
      - competition
  - File Storage: Cloudflare R2 + Cloudflare CDN
  - Database: PostgreSQL hosted on NeonDB
  - Payments: Stripe
  - IPGeolocation (listener geolocation)

  <ALTERNATIVES>
  - Add a Redis caching layer to the database
  </ALTERNATIVES>
</TECH_STACK_AND_INTEGRATIONS>



<GOALS_AND_VALUE>
- music collaboration as a social media
- Democratize music creation
- allow musicians to make a meaningful/valuable piece of work without having to complete the process of recording a song from start to finish
- tracks around 30-90s will be prioritized in the algorithm to make it simple, fun, and pair well with short form video content like Tik Tok.
- The equivalent of going from books/publications to posts on social media. New content is released daily and from more sources, and just as social media posts allow you to comment your textual thoughts/ideas on someone else's textual posts, with this app, you can comment your musical thoughts/ideas on someone else's musical posts
- the simple DAW makes it easy to get into music recording
- collaborative starter - frictionless, transactional collaboration. if a collab resonates, the artists can export to bandlab, soundtrap, etc to continue the collaboration. this allows artists to find collaborators and have a solid idea/connections BEFORE having to do administrative work like project setup.
</GOALS_AND_VALUE>

<FEATURES>
- home feed with tracks/collabs posted by user's follows mixed with popular tracks
  - click on a track to expand and see collabs on that track
- users will have profiles and can be verified artists. There will be a profile page with the user's tracks, picture, reposted tracks, liked tracks, follower count, etc

</FEATURES>



<PRIVACY_RULES>

Track access:
- if a user is private, their tracks will not load in track lists unless 
    current user is authenticated and following the track owner
- if a track is private, the track will not load in track lists
- if a track is private, the track will ONLY load for other users on the track details page, 
    and ONLY if they have the secret or they have been granted access via a group.
- No restrictions on loading private tracks if the current user is the track owner

Collabs:
- any collab on a public track MUST be public.
- the privacy status of a collab on a private track (permitted by secret key) 
    is dependent on the original track. if the original track goes public, so do all of its descendents.
- all collabs on a private track should share the same secret key
- track CANNOT go from public to private if it has collabs
- as a result, collaborating artists have no control over the privacy status of their track
</PRIVACY_RULES>

<DAW>
  - simple and easy to use DAW that allows users to record audio and add it to a track as a collab
  - tracks:
    - DAW always has a recording track. it also has 1 track for each collab.
    - when a user is collabing, they have full control over the recording track (record, delete, etc)
    - users have limited control over the collab tracks (delete, trim, etc). they cannot record on them and there must always be at least one region in each collab track. users can trim/copy/paste regions on a track, but cannot move regions between tracks.
  - user can select audio input device. they can record audio from their own DAW by using loopback audio.
</DAW>


<CAMPS_AND_TEAMS>
  camps and teams: shared musical scratchpad

Teams:
- subscription feature that allows groups of users to collaborate on tracks in a private, shared workspace.
- 10, 25, 50, 100 user plans (shared upload pool for team members)
- includes a dashbaord with track feed, folders, and members
- users can export stems from tracks to use in their DAW to turn the idea into a full song

Camps:
- feature that allows groups of users to collaborate on tracks in a private, shared workspace for a 1 week writing camp.
- 10, 25, 50, 100 user plans (shared upload pool for camp members)
- includes a dashboard with beat pool, rooms, tracks, and activity feed
- users can export stems from tracks to use in their DAW to turn the idea into a full song
</CAMPS_AND_TEAMS>
