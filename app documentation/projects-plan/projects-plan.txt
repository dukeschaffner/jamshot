
a new "project" entity that is more of a real time collaborative workspace instead of the async collaboration mechanics supported by the regular track feature. so kinda like bandlab, but with some key differences. the project could be opened in the sterio daw with less restrictions the the existing DAW so they can have closer to a standard DAW experience (moving regions between tracks, recording/uploading audio to any track, etc). this would be the source of truth/repository for the project. a project could be shared between x people. and it's kinda like a live project, where the users can make updates in real time that propagate to all users' web app sessions. here's what i think makes it different from bandlab/soundtrap: the web app would serve as the place for editing/uploading audio, but the plugin would be used to playback the project audio in the users' own daw, so they can record in their own daw where they have all their favorite tools. and the project audio that plays back in the plugin would always be up to date (im thinking the user can toggle between auto updating edits and hvaing to manually update). plugin could eventually display waveforms, gain, and playhead position for extra context (or maybe just sync DAW's transport state to web app?)
