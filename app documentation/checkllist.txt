cursor scenarios:

1 - no known adjacent windows in cache w/ target track id:
    - we want to load target track + x newer and x older tracks
        - cursor_type = "target"
        - target_track_id = target track id
        - num_padding_tracks = number of newer and older tracks to load on either side of target track

2 - one or two known adjacent windows in cache w/ target track id:
    - we want to load target track + x newer and x older tracks without loading any tracks that are already in the cache
        - cursor_type = "target"
        - target_track_id = target track id
        - num_padding_tracks = number of newer and older tracks to load on either side of target track
        - nearest_older_track_id = id of the nearest older track in the cache AND/OR
        - nearest_newer_track_id = id of the nearest newer track in the cache
        - API returns target track + sibling tracks where id > target_track_id and (id < nearest_newer_track_id if supplied LIMIT num_padding_tracks ORDER BY id ASC) and (id > nearest_older_track_id if supplied LIMIT num_padding_tracks ORDER BY id DESC)
