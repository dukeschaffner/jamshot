TECHNICAL DECISIONS

1. Discovery Method Tracking: Use URL parameters and referrer data to determine how users found content
2. Listen Duration: Track actual listening time vs. track duration for engagement metrics
3. Privacy First: Default to no tracking, require explicit consent
4. Performance: Use aggregation tables for fast analytics queries
5. Scalability: Cache geo data and use efficient database indexes
