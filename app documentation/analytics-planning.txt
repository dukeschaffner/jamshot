FREE ANALYTICS
- Track analytics
    - Current play count
    - Current listener count
    - Current engagement metrics (likes, comments, reposts, shares, collabs)
    - maybe 7 day breakdown of engagement metrics

BASIC ANALYTICS
- Track analytics (By day, week, month, year)
    - Play count
    - Listener count
    - engagement metrics (likes, comments, reposts, shares, collabs)
    - geographic data
    - age range
    - Page views

- User analytics (By day, week, month, year)
    - Play count
    - Listener count
    - Listener geographic data
    - Listener age range
    - Followers count
    - Page views


ADVANCED ANALYTICS
- Track analytics (By day, week, month, year)
    - listen duration
    - Listener retention (How long do users listen to tracks?)
    - Skip rate (when do users skip tracks?)
    - discovery method
- User analytics (By day, week, month, year)
    - listen duration
    - discovery method (how users found tracks AND how they found the user)
    - Listener retention (How long do users listen to tracks?)
