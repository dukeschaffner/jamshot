# Assets Directory

This directory should contain the following assets for the Expo app:

## Required Assets

- `icon.png` - App icon (1024x1024px)
- `splash.png` - Splash screen image (1242x2436px recommended)
- `adaptive-icon.png` - Android adaptive icon foreground (1024x1024px)
- `favicon.png` - Web favicon (48x48px)

## Generating Assets

You can use Expo's asset generation tools or create these manually. For now, placeholder images can be used for development.

## Temporary Placeholders

For initial development, you can create simple placeholder images or use Expo's default assets.
